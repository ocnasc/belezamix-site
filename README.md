# Belezamix

Site institucional da **Belezamix**, rede de duas lojas de cosméticos em Jundiaí/SP, há 20 anos na cidade.

Não é e-commerce: é uma vitrine local. O objetivo é levar quem visita até a loja física ou até o WhatsApp — não vender online.

| Loja | Endereço | Horário |

| Belezamix (Anhangabaú) | Av. Jundiaí, 376 – Anhangabaú, Jundiaí/SP, 13208-051 | Seg–Sex 8h–17h · Sáb 8h–12h |
| Belezamix Eloy Chaves | Av. Benedicto Castilho de Andrade, 558 – Parque Eloy Chaves, Jundiaí/SP, 13212-070 | Seg–Sex 8h–19h · Sáb 9h–12h |

## Estrutura de páginas

Início · Loja Anhangabaú · Loja Eloy Chaves · Marcas e categorias · Para profissionais · Como comprar

## Requisitos técnicos

- Site estático HTML, mobile-first
- Conteúdo separado em JSON (lojas, horários, marcas)
- Schema `LocalBusiness` por loja
- Imagens reais em WebP
